# Self-Evolving Agent

A self-evolving agent for Python repository tasks.

## Problem

LLM agents can solve repository tasks, but they often fail to systematically reuse successful experience and improve from previous failures.

## Scope

This project focuses on Python repository tasks, including:

- bug fixing
- test repair
- small feature implementation
- configuration changes

## Metrics

The project will evaluate the agent using:

- task success rate
- average token usage
- average tool calls
- average execution steps
